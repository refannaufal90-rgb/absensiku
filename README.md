# 📅 AbsensiKu - Aplikasi Pencatat Kehadiran Pribadi

Aplikasi absensi modern, ringan, dan praktis yang dirancang khusus untuk mencatat kehadiran harian, jam masuk/pulang kerja, durasi kerja real-time, status (WFO, WFH, Izin, Cuti, Sakit), dan rekap bulanan.

---

## ✨ Fitur Utama

1. **Jam Real-Time & Timer Kerja Berjalan**:
   - Tampilan jam digital real-time dan tanggal hari ini (Bahasa Indonesia).
   - Sambutan otomatis dinamis (*Selamat Pagi, Siang, Sore, Malam*).
   - Stopwatch/timer kerja berjalan otomatis setelah melakukan **Absen Masuk (Clock In)**.

2. **Absen Masuk & Pulang Praktis**:
   - Tombol **Absen Masuk (Clock In)** dengan 1 kali klik.
   - Tombol **Absen Pulang (Clock Out)** yang otomatis menghitung total durasi kerja harian.
   - Catatan / Notes aktivitas harian opsional.

3. **Status Kehadiran Lengkap**:
   - 🏢 **Hadir (WFO)**
   - 🏠 **WFH (Work From Home)**
   - 📝 **Izin**
   - 🌴 **Cuti**
   - 💊 **Sakit**

4. **Statistik & Ringkasan Bulanan**:
   - Total Hari Kerja bulan berjalan.
   - Total Jam Kerja akumulatif.
   - Rata-rata jam kerja per hari.
   - Rekap jumlah hari izin/cuti/sakit.

5. **Tabel Riwayat & Filter**:
   - Filter berdasarkan periode: *Bulan Ini*, *Bulan Lalu*, atau *Semua Riwayat*.
   - Filter berdasarkan status kehadiran.
   - Edit atau hapus catatan jika ada kesalahan jam atau lupa absen.
   - Tambah absensi manual untuk hari-hari sebelumnya yang terlewat.

6. **Export & Backup Data**:
   - **Export CSV / Excel**: Unduh riwayat absensi dalam format file Excel (.csv) siap pakai.
   - **Backup & Restore JSON**: Simpan data absensi ke file JSON atau pulihkan data kapan saja.
   - **Offline-ready & LocalStorage**: Data tersimpan aman di browser tanpa butuh server/database rumit.

7. **PWA & Dark/Light Mode**:
   - Tampilan elegan dengan tema Dark Mode & Light Mode.
   - Bisa di-install langsung ke Desktop / Taskbar Windows via Google Chrome atau Microsoft Edge.

---

## 🚀 Cara Menjalankan Aplikasi

Ada 2 cara mudah:

### Cara 1: Langsung Klik File Launcher
Cukup klik ganda (double-click) file:
👉 **`Buka-AbsensiKu.bat`**

### Cara 2: Buka Melalui Browser
Cukup buka file:
👉 **`index.html`** langsung di browser pilihan Anda (Google Chrome, Microsoft Edge, Brave, dll).

---

## 💻 Tips Memasang ke Desktop (PWA)

1. Buka aplikasi di **Google Chrome** atau **Microsoft Edge**.
2. Di bilah alamat browser (address bar) bagian kanan, klik ikon **"Install App"** atau tombol **"Install App"** di kanan atas aplikasi.
3. Aplikasi akan langsung terpasang seperti aplikasi desktop bawaan Windows dan bisa disematkan di Taskbar atau Start Menu!
